# Installation & Setup Guide

Follow these steps to set up, configure, and launch the PillSync application on your local machine.

---

## Prerequisites

Before starting, ensure you have the following installed:
1. **Python**: Version 3.10 or higher.
2. **Node.js & npm**: Node 18+ and npm 9+.
3. **PostgreSQL**: Version 14 or higher, running locally.

---

## Step 1: Database Setup

PillSync requires a PostgreSQL database instance.

1. **Connect to your PostgreSQL server** using pgAdmin, psql CLI, or your preferred SQL tool:
   ```bash
   psql -U postgres
   ```

2. **Create the database**:
   ```sql
   CREATE DATABASE pillsync;
   ```

3. **Verify the database exists**. The tables will be automatically generated by the FastAPI backend on startup via SQLAlchemy. However, you can review the database table relationships in `database/schema.sql`.

---

## Step 2: Backend Configuration & Startup

1. Navigate to the root directory of the PillSync project.

2. **Create a virtual environment**:
   ```bash
   python -m venv venv
   ```

3. **Activate the virtual environment**:
   - **Windows (PowerShell)**:
     ```powershell
     .\venv\Scripts\Activate.ps1
     ```
   - **Windows (CMD)**:
     ```cmd
     .\venv\Scripts\activate.bat
     ```
   - **macOS/Linux**:
     ```bash
     source venv/bin/activate
     ```

4. **Install Python packages**:
   ```bash
   pip install -r backend/requirements.txt
   ```

5. **Configure environment variables**:
   Create a `.env` file in the `backend/` directory by copying `.env.example`:
   ```bash
   cp backend/.env.example backend/.env
   ```
   Verify the environment variables match your PostgreSQL credentials:
   ```env
   DATABASE_URL=postgresql://postgres:<your_password>@localhost:5432/pillsync
   JWT_SECRET_KEY=4eb84e55bb7097c00e12d8a45b6dbd783a30364f9f72c050f443b71ab4c6b840
   JWT_ALGORITHM=HS256
   ACCESS_TOKEN_EXPIRE_MINUTES=120
   ENVIRONMENT=development
   ```

6. **Start the FastAPI backend server**:
   From the `backend/` directory, execute:
   ```bash
   uvicorn app.main:app --port 8000 --reload
   ```
   The backend will start on **`http://localhost:8000`**. On startup, it will run DB migrations and seed:
   - System Roles (`admin`, `patient`, `caregiver`).
   - Default Admin Account:
     - **Email**: `admin@pillsync.com`
     - **Password**: `admin123`

---

## Step 3: Frontend Configuration & Startup

1. Navigate to the `frontend/` directory.

2. **Install Node modules**:
   ```bash
   npm install
   ```
   *(Note: if running PowerShell on Windows and script execution is restricted, run commands using `npm.cmd`)*

3. **Launch the development server**:
   ```bash
   npm run dev
   ```
   The React frontend will be served at **`http://localhost:5173`**.

---

## Step 4: Verification & Manual Testing

1. Open your browser and navigate to **`http://localhost:5173`** to access the Landing Page.
2. Click **Register** and sign up a new account (choose Patient role).
3. Fill out the registration form. It will enforce validations (e.g. valid name, strong password).
4. After submission, you will be redirected to the **Login** page.
5. Log in with your new patient credentials. You will be redirected to the **Patient Dashboard**.
6. Navigate to **My Profile** and edit details (phone number, age, address, blood group, emergency contact). Submit changes to verify API connectivity.
7. Click **Logout**, then sign in with the default Admin credentials (`admin@pillsync.com` / `admin123`).
8. You will see the **Admin Dashboard** showing totals of 1 Patient, 1 Admin, 0 Caregivers, and the users directory directory.
